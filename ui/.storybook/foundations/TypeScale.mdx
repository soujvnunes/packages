# Type scale

Seven aliases are the only font-size utilities. Each one sets a size and a weight below the `lg` switch and above it, and a class never names a size directly.

<table>
  <thead>
    <tr>
      <th scope="col">Alias</th>
      <th scope="col">
        Size below <code>lg</code> to above
      </th>
      <th scope="col">
        Weight below <code>lg</code> to above
      </th>
    </tr>
  </thead>
  <tbody>
    {SIDES.map(([alias, size, weight]) => (
      <tr key={alias}>
        <th scope="row">
          <code>text-{alias}</code>
        </th>
        <td>{size}</td>
        <td>{weight}</td>
      </tr>
    ))}
  </tbody>
</table>

The weights differ so that two texts that share a size on the phone still read apart: `text-subtitle` and `text-title` are both 24 there, one medium and one semibold.

## Usage

- Pick the alias by the text's job, not its size. A card's name is `text-title`, the line under it `text-subtitle` or `text-body`, a timestamp `text-caption`.
- A page has one `text-display` or `text-headline`. A section opens with `text-heading`.
- A weight class beside an alias outlives the switch, so `font-semibold` cancels the alias's change at `lg`. Add one only after a walk of the screen shows the need.
